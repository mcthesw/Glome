打开包含 `S3Space3D` 的场景，点击 Godot 顶部的 **S³**。场景树与检查器之间的视口会呈现弯曲空间中的实际画面。按 **Q** 切换到选择工具，点击网格，再按 **F** 即可将它移到画面中央。

![Godot S³ 编辑器，曲面预览上方为原生工具栏，视口左上角为着色模式选择器。](/media/editor-s3-mainscreen.webp)

## 工具栏与视图模式

| 控件 | 用法 |
| --- | --- |
| **Select / Move / Rotate / Scale** | Godot 4.7 原生工具图标。视口获焦时，按 **Q / W / E / R** 切换选择、移动、旋转和缩放。初始工具为 **Move**。 |
| **Snap** | 点击图标开启吸附，或拖动时按住 **Ctrl** 临时吸附。位移按 0.5 m 弧长、旋转按 15°、缩放倍率按 0.1 递进。按住 **Shift** 可微调。 |
| **Anchor** | **New Anchor Here** 在视点前方的地面上新建锚点。选中可编辑锚点后，可用 **Duplicate at Antipode** 复制到对跖点、**Snap to Ground** 贴地或 **Face Origin** 朝向原点。这些操作均支持撤销。 |
| **View** | **Focus Selection (F)** 将选中节点移入画面。**Reset View** 恢复当前视图的初始机位。**From 3D** 把普通 3D 编辑器相机映射到 $S^3$，在 `EditorChartRadius > 0` 的锚点附近平滑过渡。 |
| **View** 中的导航项 | **Go to Origin** 回到原点标架，**Go to Antipode** 将当前视角移到对跖点，**Level Horizon** 调平地平线。**Bookmarks** 可保存、恢复、重命名或删除具名机位，书签会记住着色模式。 |
| **Overlays** | **Anchor Pins** 默认显示锚点。开启 **Selection Bounds** 可查看选中网格的投影包围盒，**Collision** 显示随选中节点移动的碰撞代理，**Lights & Cameras** 可拾取和编辑灯光与相机。 |
| **Space** | 场景中有多个空间时才出现。菜单列出相对于场景根的路径，收起时显示当前空间的名称。 |

视口左上角的 **ViewMode** 可在 `StandardLit`、`ClayClean`、`Unlit` 间切换，复用同一份烘焙几何。宿主注册的视图也会出现在其支持的空间中。需要手动重烘时，选择 **View → Rebake Preview**。

## 导航与放置场景

| 视口操作 | 效果 |
| --- | --- |
| 按住右键移动鼠标 | 环顾四周，用 **WASD** 和 **Q / E** 飞行，按住 **Shift** 加速。 |
| 右键 + 滚轮 | 在 0.25–128 m/s 间调整飞行速度，视口短暂显示新速度。**View → Reset Fly Speed** 恢复为 8 m/s。 |
| 中键拖动 / **Shift** + 中键拖动 | 围绕支点旋转 / 同时平移相机与支点。 |
| 滚轮 | 沿视线推拉。 |

从 **FileSystem** 面板把 3D 场景（`.tscn`）拖到预览中的表面。实例保留 `PackedScene` 链接，局部上轴对齐命中面的法线。选中可编辑切图时，落点须在该切图的前半球内。清空选择可在空间中独立放置锚点，普通 3D 根节点会自动包在新锚点下。

用 **Select** 点击可见几何即可选中源网格。点击锁定实例会选中实例根，在场景树为实例开启 **Editable Children** 后即可单独选择其子节点。点击地面可清空选择。按 **Ctrl+D** 会原位复制当前节点并保留场景链接。放置与复制各自只需一次撤销。

## 在球面上编辑节点

按 **W** 后拖动坐标轴或平面手柄进行平移，按 **E** 拖动三个旋转环，按 **R** 缩放可编辑的网格或锚点。拖动时，弯曲的线框会叠加在上一次烘焙的画面上，实时预览结果。松开鼠标提交一次可撤销的修改，按 **Esc** 放弃拖动。锚点的测地移动与旋转写入 `RelativeSpin`，子节点的编辑写入局部变换。操纵器距离视点的对跖点不足 0.02 弧度时，按 **F** 可重新取景。

## 查看畸变与缩放场景

检查器在锚点上显示最远顶点距离、切图角和径向压缩，在 `S3Space3D` 上显示大圆周长、赤道距离与对跖距离。

- 直接修改 **Radius**：仅改变曲率，保留原有米制坐标。
- **Scale to → Scale Entire Scene**：将半径与全部米制场景参数按 $R_{\text{new}} / R_{\text{old}}$ 等比缩放（支持撤销，跳过嵌套空间与视口）。

## 自动化接口

如需从工具脚本控制预览或热重载编辑器着色器，`GlomeEditorPlugin` 提供 `TryGetViewState`、`SetView`、`FocusNode`、`RequestRebake`、`CapturePreviewImage`、`ReloadPreviewShader` 及文件桥接配置（`BridgeDirectory` / `BridgeShaderReload`）。[编辑器扩展 API](/zh-cn/reference/resources-and-runtime/)
