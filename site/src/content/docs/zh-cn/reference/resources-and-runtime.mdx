## S3Environment 与 S3ShadingMode

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `BackgroundColor` | `Color` | `new(0.28f, 0.32f, 0.38f)` | 主射线未命中时的背景色 |
| `AmbientColor` | `Color` | `Colors.White` | 环境漫反射色 |
| `AmbientEnergy` | `float` | `0.2f` | 环境漫反射强度 |
| `FogColor` | `Color` | `new(0.28f, 0.32f, 0.38f)` | 距离雾颜色 |
| `FogDensity` | `float` | `0` | 每米指数雾密度（`0` 关闭） |
| `ShadingMode` | `S3ShadingMode` | `StandardLit` | `StandardLit`（0）、`Unlit`（1）或 `ClayClean`（2） |
| `EquatorialGroundEnabled` | `bool` | `true` | 启用 $p_y = 0$ 解析赤道地面（须同时在 `S3Space3D` 启用） |
| `GroundMaterial` | `StandardMaterial3D?` | `null` | 地面材质；留空时绘制程序化网格 |

`EnvironmentBlock Capture(int groundMaterial)` 将颜色线性化，打包着色模式、地面索引与地面 UV 变换 `(0.25 × Uv1Scale.XY, Uv1Offset.XY)`。

## S3RenderProgram、ProgramBuffer 与 GlomeStandardProgram

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Shader` | `RDShaderFile?` | `null` | 选择带 `#[compute]` 的 `.glsl` 文件（如 `cel.glsl`） |
| `SpecializationValues` | `int[]` | `[]` | 每个整数为常量 ID `0` 编译一条管线；留空使用着色器默认值 |
| `CaptureSet1` | `Func<ProgramBuffer[]>?` | `null` | 构造与 `Rebuild` 时回调，数组下标对应 Set 1 绑定号 |

- `ProgramBuffer(RenderingDevice.UniformType Type, byte[] Data)`：`UniformBuffer` 或 `StorageBuffer` 字节数据（排队上传期间保持数组内容不变）。
- `GlomeStandardProgram()`：预加载 `res://addons/glome/Shaders/glome_standard.glsl` 的 `S3RenderProgram`。

## S3BakeSnapshot 与 GlomeBakeOptions

```csharp title="记录类型"
S3BakeSnapshot(long Revision, BakedGeometry Geometry, S3CollisionWorld Collision,
    Node3D[]? TriangleOwners, GlomeMaterials? Materials, GlomeLight[] Lights,
    EnvironmentBlock Environment)

GlomeBakeOptions(double? RadiusOverride = null,
    BakeVisibility Visibility = BakeVisibility.HonoredUpToRoot,
    Func<Material?, SurfaceTag>? ResolveMaterial = null,
    Action<S3Anchor3D, S3Frame, Transform3D>? OnAnchor = null,
    Action<int, CollisionShape3D, S3Frame, Transform3D>? OnProxy = null,
    bool IncludeOwners = false, Predicate<D4>? GroundMask = null)
```

- `Visibility`：`HonoredUpToRoot`（0）检查节点及至空间根的祖先可见性；`SelfVisible`（1）仅检查节点自身。已启用的碰撞体在两种策略下均参与烘焙。
- `ResolveMaterial`：用自定义 `SurfaceTag(Material, Surface, Traversal)` 替代内置 `StandardMaterial3D` 打包（此时 `Materials` 为空）。
- `IncludeOwners`：将重排后的 BVH 三角形映射回归属 `S3Anchor3D`（或网格），用于编辑器拾取。
- `GroundMask`：CPU 地面求交的纯值谓词，输入单位交点 `x`，返回 `true` 保留地面（与 GPU `GLOME_GROUND_HOLE` 互补）。

## GlomeBaker

```csharp title="GlomeBaker"
public static S3BakeSnapshot Bake(S3Space3D space, GlomeBakeOptions? options = null)
public static Task<S3BakeSnapshot> BakeAsync(S3Space3D space,
    GlomeBakeOptions? options = null, CancellationToken cancellationToken = default)
```

在 Godot 主线程调用。`BakeAsync` 在主线程提取节点与回调，在工作线程投影三角形并构建 BVH 与碰撞世界；若期间被更新的烘焙或 `RequestRebake()` 取代，发布前抛出 `OperationCanceledException` 防止旧结果覆盖。

## GlomeMaterials、GlomeBuffers 与 GlomeLight

- `GlomeMaterials(MaterialRecord[] Records, TextureBank[] Banks)`：内置材质表（索引 `0` 为 `MaterialRecord.White`）及至多 4 组 sRGB `TextureBank`。
- `GlomeBuffers.Pack(S3BakeSnapshot)` / `Pack(BakedGeometry, MaterialRecord[], byte[], EnvironmentBlock, TextureBank[])`：按 [Set 0 公共契约](/zh-cn/reference/compute-abi/)打包缓冲区。调用 `Draw` 时传入实际的 `Geometry.Nodes.Length`。
- `GlomeLight.Directional(pole, radiance, shadows)` / `Omni(position, radiance, metres, radius, shadows)` / `Pack(lights)`：按 `LightGroup` 顺序（`Directional`、`ShadowedDirectional`、`Omni`、`ShadowedOmni`）分组并写入 16 字节计数头。

## GlomeComputeRenderer

```csharp title="构造函数"
GlomeComputeRenderer(S3BakeSnapshot snapshot, Vector2I size, S3RenderProgram? program = null,
    byte[]? probes = null, bool capture = false, string timingPrefix = "")
GlomeComputeRenderer(GlomeBuffers buffers, Vector2I size, S3RenderProgram? program = null,
    byte[]? probes = null, bool capture = false, string timingPrefix = "")
```

| 成员 | 作用 |
| --- | --- |
| `const double VerticalFov` | 默认垂直视场角（`70°`） |
| `Texture2Drd Output` | 当前输出纹理包装对象 |
| `ConcurrentQueue<RenderNotice> Notices` | 包含 `Error`、`NoDevice`、`Probe`、`FrameSaved` 的线程安全通知队列 |
| `Draw(view, radius, nodeCount, elapsedSeconds, probeCount = 0, timingLabel = null, pipeline = 0, verticalFov = VerticalFov)` | 调度图像渲染（`probeCount == 0`）或诊断探针（`probeCount > 0`） |
| `Resize(Vector2I size)` | 调整输出尺寸 |
| `Rebuild(GlomeBuffers scene, byte[]? probes = null, string timingPrefix = "")` | 上传新几何缓冲并重新采集 Set 1 |
| `UpdateLight(int index, LightRecord record)` | 覆写字节偏移 `16 + 32i` 处的灯光记录 |
| `UpdateEnvironment(EnvironmentBlock env)` | 替换 80 字节环境统一块 |
| `UpdateProgramBuffer(int binding, byte[] snapshot)` | 从字节 `0` 覆写已有 Set 1 缓冲 |
| `Task ReloadShader(RDShaderSpirV spirv)` | 原子替换计算管线；失败时保持原着色器继续运行 |
| `Task<bool> CaptureFrame(string path)` / `SaveFrame(string path)` | 写出 PNG（构造时需 `capture: true`） |
| `PollProbe()` | 将时间戳与探针回读结果推入 `Notices` |
| `Dispose()` | 在渲染线程释放 GPU 资源 |

## 切图与碰撞适配器

| 工具类 | 作用 |
| --- | --- |
| `GlomeChart.Walk(parent, transform, visit)` | 深度优先遍历同一切图内的后代节点（遇嵌套锚点、空间或视口停止） |
| `ChartCamera.FromUnfolded` / `FromTangent` / `Blend` | 将 Godot 3D 编辑器相机变换转换或混合为 `S3Frame` |
| `CollisionShapeAdapter.Create` / `Box` | 将 `BoxShape3D`、`WalkableBoxShape3D`、`CylinderShape3D` 转为 `CollisionProxy` |

## 编辑器扩展 API（`Glome.Editor`，`#if TOOLS`）

- **`IGlomeEditorViewProvider`**：实现 `Id`、`DisplayName`、`AppliesTo(space)`、`Bake(space)`（及可选 `Resolution`、`DisplayFilter`、`Animated`），通过 `GlomeEditorViews.Register(provider)` 注册，释放返回的句柄即可注销。
- **`GlomeEditorView(Snapshot, Buffers, InitialView, Program = null, PrepareFrame = null)`**：`PrepareFrame(renderer, view, elapsed)` 可逐帧更新 Set 1 数据并返回管线索引。
- **`GlomeEditorPlugin`**：公开 `BridgeDirectory`、`BridgeShaderReload`、`TryGetViewState`、`SetView`、`FocusNode`、`RequestRebake`、`CapturePreviewImage` 与 `ReloadPreviewShader`。
- **`GlomeInspectorPlugin`**：在检查器提供半径大圆读数、可撤销的 **Scale Entire Scene** 与锚点径向压缩诊断。
